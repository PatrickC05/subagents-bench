Our operational definition: an interactive agent stays correct, predictable and responsive while the user keeps talking to it.

When we send these requests, we are assuming the agent is interactive, so that is what we have to evaluate. We define interactivity operationally with four measures. Correctness: the fix rate of the bugs we send. Accurate estimates: how close its ETA is to when the fix is actually done. Time to response: how fast questions get a reply while work is running. And handling abrupt changes: whether it deals with urgent requests and shifted priorities.
