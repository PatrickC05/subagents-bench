We test four scenarios, each adding one thing. One: bugs arrive over time, the baseline. Two: every bug also asks right away how long it will take, so we can grade the estimate. Three: questions about the code arrive between bugs; estimates are only asked for bugs. Four: some requests are urgent and should jump the queue, which is the hardest to grade, so it comes last. Each scenario is run with each of the three agent settings.
