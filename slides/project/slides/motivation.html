Agent thinking and running commands on bug 1

New messages wait

A coding agent reads new messages only between its own steps. While it works, the user waits.

Picture how people actually use coding agents. You ask for a fix, and two minutes later you ask a question about the code, then you ask when the fix will land, then something urgent comes up. These requests are related, the same repository, but they are not the same task. An agent reads a new message only between its own steps, so while it is thinking or running a command, everything else waits. That is the user experience problem we care about.
