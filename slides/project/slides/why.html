Why does delegation lose? Because the waiting isn’t where we expected. Almost every bug that found the orchestrator busy arrived while it was thinking, in a model call, not while it was running a command. The single agent’s commands are tiny, a third of a second at the median, even when we required it to test each fix. And single calls can be huge: one DeepSeek call reasoned for about 21 thousand tokens over four and a half minutes. A manager coordinating subagents thinks longer per call, so moving the commands elsewhere doesn’t help.
