Then we changed what the user asks for. Between bugs, the user now asks questions about the code, checks status, and sometimes marks a bug urgent. Now the picture flips. The single agent answered only 56 percent of questions, with a median of almost five minutes. Both subagent conditions answered 81 percent within about a minute, and status checks in 42 seconds, while fixing the same number of bugs or more. And interestingly, once questions arrive, the orchestrator with all tools starts delegating by itself. Four sessions per condition, so these are directions.
