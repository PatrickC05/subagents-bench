Metrics

What we measure for every request

MetricHow
Time to replySeconds from a request being sent to the agent’s first reply to it
Time to startSeconds until any agent opens or edits the files the bug touches
Bugs fixedThe benchmark’s hidden tests for each bug, after the session
Estimate errorThe ETA the agent gave against when it said the bug was done, and whether it was
AnswersWhether a question was answered, how fast, and whether a judge marks it correct

Timed sessions on SWE-sweep: a real repository with many bugs, each graded on its own, so each bug can be its own request.

These are the metrics we keep for every request: time to the agent's first reply, time until anyone starts on the bug's files, whether the bug is fixed by the hidden tests, how far off the agent's time estimate was, whether questions are answered, how fast and how correctly, and the cost. The sessions run on SWE-sweep, where a repository has many bugs that are graded one by one, so each bug can be its own request.
