Is the agent there when you ask?

A simulated user works with the agent on one repository for {minutes} minutes. A bug arrives every {interval} minutes ({n_bugs} in all), two questions about the code come between bugs, a status check asks how long the open bugs will take, and bug 3 is urgent. The user sees only what the agent sends with reply, so this measures how fast and how well questions are answered, whether bugs get fixed, and whether the agent's estimates of its own work hold. Two bugs-only controls get the same bugs at the same times and nothing else, so the gap to them is what the requests cost. Orchestrator: DeepSeek-V4.1-Flash. Subagents: Gemma-4-31B, 20 steps each, up to 3 at once.

Waited to be read: until the message entered the agent's conversation (it arrives between steps). Medians count a message never answered as infinitely late. Controls (dashed cards) have no ids or replies: their bugs are numbered by position and show only pickup (waited to be read, first edit after) and fixes.
